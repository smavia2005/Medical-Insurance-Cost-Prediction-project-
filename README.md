# Medical Insurance Cost Prediction - ML Project

A Machine Learning project to predict medical insurance costs.

### 🎯 Problem Statement
To predict insurance charges based on age, gender, BMI, children, smoker, region.

### 📁 Dataset
- insurance.csv (age, sex, bmi, children, smoker, region, charges)

### 🛠️ Tech Stack
Python, Pandas, Scikit-Learn, Matplotlib, Seaborn, Streamlit

### ⚙️ Workflow
Data Cleaning -> EDA -> Model Training (Random Forest) -> Evaluation (R2 Score) -> App Deployment

### 🚀 Run
streamlit run app.py
